# Chatty - Simple chat client

## Prelude
This is a side project as a mean to learn websocket in Go.

## Get Started
Clone this repository and `cd` into the project directory. Then,
```bash
# install required golang dependencies
go mod download

# install required typescript dependencies
npm install

# run or build the server
go run cmd/chatty/main.go
go build cmd/chatty/main.go
```


## Stack
- Human written codebase
- No framework on frontend and backend.
- Go 1.26 or newer
- Typescript 6
- HTML & CSS
- [goose](https://github.com/pressly/goose) migration tool
